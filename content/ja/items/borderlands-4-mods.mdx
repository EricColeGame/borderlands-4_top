## ボルダーランズ4 Modの導入方法（Steam＆Epic Games）

標準的なpak形式のModをインストールするには、ゲームのルートディレクトリにアクセスする必要があります。[Steam公式クライアント](https://store.steampowered.com/)またはEpic Games Storeのどちらから起動する場合でも、手順は非常にシンプルです。

```
ゲームルートフォルダのパス例:
Steam:  ...\Steam\steamapps\common\Borderlands 4\
Epic:   ...\Epic Games\Borderlands 4\
```

### ゲームファイルの場所を確認する

1. **Steamユーザー:** Steamライブラリを開き、『Borderlands 4』を右クリックして**管理** > **ローカルファイルを閲覧**を選択します。
2. **Epic Gamesユーザー:** Epicライブラリを開き、ゲームタイルの**3つの点（...）**をクリックし、**管理**を選択してインストールパスの横にあるフォルダアイコンをクリックします。
3. Windowsのエクスプローラーで**フォルダオプション > 表示タブ**を開き、「**登録されている拡張子は表示しない**」のチェックを外して、拡張子が表示されるようにしてください。

### 標準的なPAK Modのインストール手順

ほとんどのビジュアル、UI、バランス調整Modは、raw pakファイルを含む圧縮された`.zip`または`.rar`アーカイブとして配布されています。

| ステップ | 操作内容 | 対象ディレクトリ / 備考 |
| :--- | :--- | :--- |
| **ステップ 1** | サブフォルダへ移動 | `Borderlands 4\OakGame\Content\Paks\` へ移動 |
| **ステップ 2** | Modsフォルダを作成 | `Paks` 内で右クリックし、`~mods`（または `mods`）という新しいフォルダを作成 |
| **ステップ 3** | ファイルを解凍 | 7-Zip、WinRAR、またはWindows標準機能を使ってダウンロードしたアーカイブを解凍 |
| **ステップ 4** | ファイルを配置 | `.pak` および関連ファイルを新しく作成した `mods` フォルダにコピー |
| **ステップ 5** | 確認＆起動 | ゲームを起動してModが正しく適用されているか確認 |

## 最適化INI設定および起動スキップの導入

パフォーマンス向上Modやイントロスキップは、通常のpakファイルとは異なるディレクトリを使用します。間違ったフォルダに配置すると正常に読み込まれません。

### パフォーマンス調整用INIの設定

設定の調整により、エンジンのレンダリングパラメータを変更し、激しい戦闘時のフレーム落ちを改善します。

1. 最適化済みの `Engine.ini` 差し替えファイルをダウンロードします。
2. `Win + R` キーを押し、以下を貼り付けて実行します：`%USERPROFILE%\Documents\My Games\Borderlands 4\Saved\Config\Windows\`
3. バックアップとして、既存の `Engine.ini` を `Engine.ini.bak` にリネームします。
4. ダウンロードしたカスタム `Engine.ini` をこのディレクトリにドラッグ＆ドロップします。

### エンジン設定調整によるパフォーマンスへの影響

| 設定項目 | デフォルト状態 | Modによる最適化 | 期待されるFPS向上 |
| :--- | :--- | :--- | :--- |
| **Lumen Global Illumination** | 高品質バウンス | 最適化トレースサンプル | +10% 〜 +18% FPS |
| **Screen Space Reflections** | フル解像度ダイナミック | ディフューズカリング有効化 | +8% 〜 +15% FPS |
| **Volumetric Fog Density** | ウルトラサンプリング | バランスステップ計算 | +5% 〜 +10% FPS |
| **起動スプラッシュのスキップ** | 動画再生有効 | エンジン直接初期化 | 起動時間が15〜25秒短縮 |

## エンドゲームおよびレベルブースト用セーブデータのインポート

複数のVault Hunterでキャンペーンを最初からやり直すことなくエンドゲームビルドを試したい場合、セーブデータ複合化ツールを使うことで最大レベルのキャラクタープロファイルをインポートできます。

```
Steamセーブデータのディレクトリ:
%USERPROFILE%\Documents\My Games\Borderlands 4\Saved\SaveGames\<SteamID64>\Client\
```

### セーブファイルの導入手順

1. **現在の進行状況をバックアップ:** セーブファイルを編集する前に、必ず `SaveGames` フォルダ全体を別の安全な場所にコピーしてください。
2. **SteamID64の取得:** Steamアカウント設定またはコミュニティの検索ツールから自身のアカウントIDを取得します。
3. **プロファイルセーブの変換:** コミュニティのセーブデータ暗号化/複合化ツールを使用し、ダウンロードしたYAML/キャラクターテンプレートをご自身のSteamIDと紐付けます。
4. **ファイルの配置:** 変換された数字名の `.sav` ファイルを現在使用中のSteamプロファイルフォルダに貼り付けます。
5. **ゲーム内で読み込み:** ゲームを起動し、「**Vault Hunterのロード**」を選択して、最大レベルのキャラクターがリストに追加されていることを確認します。

*注：プレイヤーからの報告によると、セーブデータ注入ツールは現在Steam版向けに最適化されており、他のストアクライアントでは別の変換スクリプトが必要になる場合があります。*

## マルチプレイヤーの互換性とMod利用時のマナー

オンラインマルチプレイでModを使用する際は、ホスト権限のルールに十分注意する必要があります。ボルダーランズはP2P（ピアツーピア）ネットワークアーキテクチャを採用しているため、Modの種類によってセッション内での挙動が異なります。

* **ホスト側の優先:** ワールドスケーリング、経験値倍率、戦利品のドロップ率に影響を与えるバランスModは、セッションホストが導入していればパーティ全員に適用されます。
* **クライアント側のビジュアル:** HUDの変更、ReShadeフィルター、オーディオの差し替えなどはローカルプレイヤーのみに影響し、チームメイトとの非同期（同期ズレ）を引き起こすことはありません。
* **セーブデータの整合性:** 公開マッチメイキングで過度なステータスを持つ改造アイテムや不正なスキルポイントを使用すると、他のプレイヤーのゲーム体験を損なう恐れがあります。ドロップ倍率の高いModなどを使用する場合は、Co-opセッションを始める前に必ずフレンドに確認してください。

## よくある質問（FAQ）

### ボルダーランズ4でModを使ってCo-opをプレイするとBANされますか？
いいえ。ボルダーランズシリーズはP2P型の協力プレイを採用しており、厳格なアンチチートシステムは導入されていません。ただし、全員が快適にプレイできるよう、参加者の同意なしに公開ロビーで極端なダメージ増加やドロップ率変更Modを使用することは避けてください。

### ボルダーランズ4のModフォルダはどこにありますか？
標準的なpak形式のModの場合、`...\Borderlands 4\OakGame\Content\Paks\` 内に `mods`（または `~mods`）というフォルダを作成して配置します。設定調整ファイル（INIなど）は `%USERPROFILE%\Documents\My Games\Borderlands 4\Saved\Config\Windows\` に配置します。

### ボルダーランズ4でModを導入するとSteamの実績が無効になりますか？
一般的なビジュアル、パフォーマンス、インベントリ拡張Modを導入しても、プラットフォームの実績が無効になることはありません。ただし、メモリに深くアクセスする一部のユーティリティや大規模なオーバーホールプラグインは、実績トリガーのスクリプトと競合する可能性があります。

### Modを導入したらゲームが起動時にクラッシュします。どうすればいいですか？
最近 `Paks\mods` フォルダに追加したファイルを1つずつ削除し、原因となっているファイルを特定してください。`Engine.ini` の調整によって起動エラーが発生した場合は、そのファイルを削除した上でSteamまたはEpic Gamesからゲームファイルの整合性を確認し、デフォルト設定を復元してください。
