## 4人のプレイアブル・ヴォルト・ハンター一覧

本作のメインラインナップには、モジュール式のキャラクター育成を軸に設計された4つの完全新規アーキタイプが登場します。[『ボーダーランズ4』公式サイト](https://borderlands.2k.com/en-US/borderlands-4/game-info/vault-hunters/)によると、すべてのキャラクターは3つの固有アクションスキルと、ソケット可能なアビリティやパッシブ強化が満載された3つの広大な分岐スキルツリーを備えています。

| ヴォルト・ハンター | アーキタイプ / クラス | 主な戦闘スタイル | アクションスキルのテーマ | おすすめのプレイスタイル |
| :--- | :--- | :--- | :--- | :--- |
| **ヴェックス（Vex）** | セイレーン（The Siren） | 属性ダメージ＆クラウドコントロール | フェーズを帯びた神秘の力 | 中〜遠距離のキャスター |
| **ラファ（Rafa）** | エグゾ・ソルジャー（The Exo-Soldier） | 高機動力＆戦術的火力 | エグゾスーツ・オーバードライブ＆重火器 | ラン＆ガンの銃撃戦 |
| **エイモン（Amon）** | フォージナイト（The Forgeknight） | 近接戦闘＆重防御 | 灼熱の兵器群＆バリア技術 | 前線で戦うブルーザー / タンク |
| **ハーロウ（Harlowe）** | グラヴィター（The Gravitar） | 空間操作＆特異点制御 | 重力場＆キネティックフォース | 範囲攻撃によるゾーニング |

それぞれの**Borderlands 4 Vault Hunters**は、ガンプレイとアビリティの組み合わせにおいて独自のアプローチを持っており、プレイヤーはエンドゲーム向けビルドを構築する際に圧倒的な自由度を体験できます。

## ヴェックス（Vex）：セイレーン

セイレーンは常に本シリーズの神秘的な柱となってきましたが、ヴェックスはその伝統を受け継ぎつつ、アグレッシブで属性に特化したアビリティセットを持っています。セイレーンとして宇宙のエネルギーを操り、戦闘の流れを支配し、継続的な特大ダメージ（DoT）を与え、危険なエリートエネミーを行動不能に追い込みます。

```

│ フェーズトレント │ │ クロノグラスプ  │ │プリズマティック │
```

### スキルツリーとアクションスキルの概要

| ツリーブランチ | 主な焦点 | 主なパッシブ効果 | 相性の良い要素 |
| :--- | :--- | :--- | :--- |
| **カタリスト（Catalyst）** | 状態異常＆エレメンタル確率 | ショック、コロッシブ、インセンディオリのダメージ間隔/威力を強化 | マリワン社製武器＆属性武器 |
| **エーテルウォード（Aether Ward）** | シールド＆ヘルス吸収 | 与えている属性ダメージを自身の体力回復に変換 | 生存力を重視したソロビルド |

### ヴェックスのプレイスタイル

ヴェックスは戦場全体に属性のカオスをまき散らすのを得意とします。状態異常によって高いダメージ効率を維持しつつ、敵の動きを自在にコントロールしたいプレイヤーにとって、ヴェックスは極めるのが最も楽しい**Borderlands 4 Vault Hunters**の一人となるでしょう。

## ラファ（Rafa）：エグゾ・ソルジャー

純粋な銃撃戦、戦術的な立ち回り、そして圧倒的な機械化火力を愛するなら、ラファこそが最適な選択肢です。最先端のエグゾスーツ技術を装備したラファは、従来のソルジャークラスの系譜を受け継ぎながら、未来的な高機動性と展開型重火器を融合させています。

### アクションスキルの詳細

* **エグゾ・オーバードライブ（Exo-Overdrive）：** ラファの移動速度、リロード速度、連射速度を大幅に強化し、自動小銃を弾幕マシンへと変貌させます。
* **マイクロミサイル・サルヴォ（Micro-Missile Salvo）：** 肩部のマウントから追尾ミサイルの斉射を放ち、重装甲の敵を蜂の巣にします。
* **タクティカル・ハードライトバリア（Tactical Hardlight Barrier）：** 敵の攻撃を吸収し、味方の射撃威力を増幅するエネルギーバリアを展開します。

| ラファのスキルパス | 主な戦闘役割 | 相性抜群の武器種 | 主要なマスタリーパーク |
| :--- | :--- | :--- | :--- |
| **バリスティクス・ヴァンガード（Ballistics Vanguard）** | 純粋なDPS＆クリティカルヒット | アサルトライフル、SMG | クリティカルヒット時に弾薬を回収 |
| **オードナンス・エンジニアリング（Ordnance Engineering）** | 爆発＆スプラッシュダメージ | 重火器（ランチャー）、グレネード | スプラッシュキルでミサイルのクールダウンがリセット |
| **エイペックス・モビリティ（Apex Mobility）** | ダッシュ射撃＆スライドアタック | ショットガン、ピストル | スライド中の射撃でスタック式のシールド回復を獲得 |

ラファは**Borderlands 4 Vault Hunters**の中でもラン＆ガンを好むプレイヤーの代表格であり、直感的な操作性と、ハイレベルな移動テクニックによる非常に高いスキル上限を兼ね備えています。

## エイモン（Amon）：フォージナイト

エイモンは、重厚なパワーアーマーと灼熱の鍛冶クラフトアビリティを融合させることで、近接型アーキタイプの定義を刷新します。フォージナイトとして、激しい猛攻を耐え忍びながら、破壊的な近接攻撃や至近距離での爆発打撃を繰り出します。

```
[ 前線交戦スタイル: エイモン ]
   ├── 近接射程まで一気に突撃
   ├── モルテンシールドを展開（ダメージを吸収）
   └── フォージハンマーを炸裂（広範囲の炎の衝撃波）
```

### エイモンのおすすめ戦略

1. **ダメージ軽減をスタックする：** 吸収した衝撃ダメージをボーナス近接ダメージに変換するパッシブスキルに投資しましょう。
2. **一気に間合いを詰める：** リープ（跳躍）やダッシュアビリティを活用してスナイパーの射線をすり抜け、高脅威なターゲットにプレッシャーを与えます。
3. **点火ループ（Ignition Loops）：** エイモンの灼熱近接攻撃とスプラッシュ武器を組み合わせることで、連続した炎爆発を発生させます。

## ハーロウ（Harlowe）：グラヴィター

ハーロウは、シリーズに全く新しいクラスの概念である「グラヴィター」をもたらします。高度な空間物理学を駆使して重力を歪め、敵を強制的に移動させ、強力な運動圧力で押し潰し、戦闘エリア全体を完全に掌握します。

| スキルツリー | 主なメカニクス | 理想的なチーム役割 | ソロ適性スコア |
| :--- | :--- | :--- | :--- |
| **イベントホライズン（Event Horizon）** | ブラックホール＆特異点への引き寄せ | 敵の集敵＆AoE攻撃の起点作り | 9/10 |
| **キネティックベクター（Kinetic Vector）** | ノックバック＆速度連動型ダメージ | 敵陣の撹乱＆狙撃手の迎撃 | 8.5/10 |
| **ヌルデンシティ（Null Density）** | 反重力浮遊＆アーマー破壊 | エリートのデバフ＆ボスの高速撃破 | 9.5/10 |

### ハーロウのゲームプレイループ

ハーロウのアビリティは敵を一箇所に密集させることができます。これにより、グレネードMOD、ロケットランチャー、チームの連携攻撃による壊滅的なコンボが可能になります。戦場の空間構造そのものを操りたいプレイヤーにとって、ハーロウはこれまでに設計された**Borderlands 4 Vault Hunters**の中で最も革新的なキャラクターの一人と言えます。

## 新スキルツリーシステムの仕組み

『ボーダーランズ4』では、キャラクターカスタマイズが大幅な進化を遂げました。固定されたスキル割り振りではなく、各ヴォルト・ハンターは3つのスキルツリーに直接組み込まれたモジュール式ソケットシステムの恩恵を受けられます。

```
       ┌───────────────────────────────┐
       │     アクティブアクションスキル枠    │
       └──────────────┬────────────────┘
                      │
     ┌────────────────┴────────────────┐
     │ オーグメント / ソケットモディファイア │
     └────────────────┬────────────────┘
                      │
     ┌────────────────┴────────────────┐
     │    パッシブツリー マイルストーンパーク   │
     └─────────────────────────────────┘
```

### スキルシステムの主な改善点

* **ソケット可能なアビリティモディファイア：** 属性タイプの変更、追尾機能の付加、ハザードエリア（ダメージゾーン）の残留など、アクションスキルの挙動そのものを改変可能。
* **柔軟なスキルリセット（振り直し）：** 各地の自販機ステーションやファストトラベル拠点で、法外なゲーム内コストを支払うことなく手軽にパッシブスキルの再配分が可能です。
* **ツリー間のシナジー：** あるブランチのパッシブ効果が別のブランチのメカニクス特性を直接強化できるため、エンドゲームコンテンツでハイブリッドビルドが大いに活躍します。

## 最初のヴォルト・ハンターの選び方

最初のプレイでどのキャラクターを選ぶか迷っている場合は、好みのプレイスタイルに合わせた以下の指標を参考にしてください：

| あなたが好きなスタイルが… | おすすめのヴォルト・ハンター | 選ぶべき理由 |
| :--- | :--- | :--- |
| **テンポの良い銃撃戦＆射撃メカニクス** | **ラファ（Exo-Soldier）** | トップクラスのリロード速度、連射力、直接的な武器補正。 |
| **魔法、スキル連発＆属性コンボ** | **ヴェックス（Siren）** | 圧倒的な属性重複付与と広範囲の神秘的AoEパワー。 |
| **攻撃を耐え抜くタフネス＆豪快な近接攻撃** | **エイモン（Forgeknight）** | 最高の装甲値と爆発的な至近距離ストライク。 |
| **戦術的な空間制御＆敵の統制** | **ハーロウ（Gravitar）** | 唯一無二の空間操作と特異点による集敵能力。 |

どの道を選んだとしても、**Borderlands 4 Vault Hunters**は、何百時間にも及ぶトレジャーハント、銃撃戦、そしてビルド構築の試行錯誤を存分に楽しめるだけの深みと柔軟性を備えています。

## よくある質問（FAQ）

### 『ボーダーランズ4』の発売時点でプレイ可能なヴォルト・ハンターは何人ですか？
『ボーダーランズ4』は、ヴェックス（セイレーン）、ラファ（エグゾ・ソルジャー）、エイモン（フォージナイト）、ハーロウ（グラヴィター）の完全新規4人のプレイアブル・ヴォルト・ハンターでリリースされます。

### 『ボーダーランズ4』のヴォルト・ハンターはスキルポイントの振り直し（リスペック）ができますか？
はい。ゲーム内の主要な拠点やファストトラベルゾーンにあるクイック・チェンジ・ステーションで、スキルポイントやソケットモディファイアを簡単にリセットして再割り振りできます。

### ソロプレイに最もおすすめの『ボーダーランズ4』ヴォルト・ハンターは誰ですか？
ラファ（エグゾ・ソルジャー）とヴェックス（セイレーン）の双方がソロプレイに最適な選択肢です。ラファは自己防衛用のシールドと武器強化を備えており、ヴェックスは安定したヘルス吸収と広範な敵のコントロール能力により、大群を安全に処理できます。

### 『ボーダーランズ4』のヴォルト・ハンターは複数のアクションスキルを持っていますか？
はい。すべてのヴォルト・ハンターは3つの固有アクションスキルと3つの分岐スキルツリーを持っており、単体への瞬間火力、防御サポート、広範囲のクラウドコントロールなど、状況に応じてプライマリアビリティを自由に切り替えることができます。
