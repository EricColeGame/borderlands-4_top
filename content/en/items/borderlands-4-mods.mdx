## How to Install Borderlands 4 Mods (Steam & Epic Games)

Installing standard pak mods requires accessing your game’s root directory. The installation process is straightforward whether you launch via the Epic Games Store or the [official Steam client](https://store.steampowered.com/).

```
Game Root Folder Path Reference:
Steam:  ...\Steam\steamapps\common\Borderlands 4\
Epic:   ...\Epic Games\Borderlands 4\
```

### Locating Your Game Files

1. **Steam Users:** Open your Steam Library, right-click *Borderlands 4*, select **Manage**, then click **Browse local files**.
2. **Epic Games Users:** Open your Epic Library, locate the game tile, click the **three horizontal dots (... )**, select **Manage**, and click the folder icon next to the installation path.
3. Ensure file extensions are visible in Windows Explorer by opening **Folder Options > View tab** and unchecking **Hide extensions for known file types**.

### Standard PAK Mod Installation

Most cosmetic, UI, and balance adjustments are distributed as compressed `.zip` or `.rar` archives containing raw pak files.

| Step | Action | Target Directory / Notes |
| :--- | :--- | :--- |
| **Step 1** | Navigate to Game Subfolder | Go to `Borderlands 4\OakGame\Content\Paks\` |
| **Step 2** | Create Mods Folder | Right-click inside `Paks` and create a new folder named `~mods` (or `mods`) |
| **Step 3** | Extract Files | Extract your downloaded archive using 7-Zip, WinRAR, or Windows Extractor |
| **Step 4** | Transfer Files | Copy the `.pak` and associated files into the new `mods` folder |
| **Step 5** | Verify & Launch | Boot the game to confirm mod activation |

## Installing Optimization INI Fixes and Splash Skips

Performance mods and intro bypasses use different directories than standard pak files. Placing them in the wrong folder will prevent them from loading.

### Performance INI Configuration

Config tweaks modify engine rendering parameters to recover lost frames during intense gunfights.

1. Download the optimized `Engine.ini` replacement file.
2. Press `Win + R` and paste: `%USERPROFILE%\Documents\My Games\Borderlands 4\Saved\Config\Windows\`
3. Rename your original `Engine.ini` to `Engine.ini.bak` to preserve a safe backup.
4. Drag and drop the downloaded custom `Engine.ini` into the directory.

## Multiplayer Compatibility and Mod Etiquette

Running mods while playing online requires careful attention to host authority rules. Because Borderlands relies on a peer-to-peer networking architecture, certain modifications behave differently across sessions:

* **Host-Side Priority:** Balance mods affecting world scaling, XP gain multipliers, and loot drops apply to everyone in the party if the session host has them installed.
* **Client-Side Visuals:** HUD changes, ReShade filters, and audio replacements only affect the local player and do not cause desyncs with teammates.
* **Save File Integrity:** Using modded items with excessive stats or altered skill points in public matchmaking can negatively impact other players' enjoyment. Always check with friends before running high-multiplier drop mods during co-op sessions.

## Frequently Asked Questions

### Can you get banned for using Borderlands 4 mods in co-op?
No. Borderlands titles use peer-to-peer cooperative multiplayer without invasive anti-cheat systems. However, to ensure a fun experience for everyone, avoid using extreme damage or drop-rate mods in open public lobbies without group consent.

### Where is the Borderlands 4 mods folder located?
For standard pak mods, create a folder named `mods` (or `~mods`) inside `...\Borderlands 4\OakGame\Content\Paks\`. For configuration tweaks, files belong in `%USERPROFILE%\Documents\My Games\Borderlands 4\Saved\Config\Windows\`.

### Do Borderlands 4 mods disable achievements on Steam?
In general, standard visual, performance, and inventory modifications do not disable platform achievements. However, certain heavy memory-hooking utilities or total conversion plugins may interfere with tracking script triggers.

### What should I do if a mod crashes my game on startup?
Remove recently added files from your `Paks\mods` folder one by one to identify the incompatible file. If an `Engine.ini` tweak causes launch errors, delete it and verify your game files via Steam or Epic Games to restore default settings.
